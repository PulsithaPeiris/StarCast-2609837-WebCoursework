# StarCast

StarCast is a movie recommendation site which was created for the CM1605 coursework of Web Technology.

## Overview
StarCast allows users to browse its movie library and find interesting movies. Filtering of movies is also implemented within StarCast to allow users to pinpoint their movies of interest. Finally a community driven feedback form is created to show the community recommendations and comments about movies. All which was made possible through HTML5, CSS3, JavaScript and XML.

## Features
    - Responsive navigation bar with hamburger menu style
    - Responsive grid layout which adapts for smaller screen sizes
    - Call-To-Action buttons
    - Filtering movies by title search
    - Filtering movies through genre
    - XML file for data storage
    - Hover effects with navigation elements, movie cards and buttons
    - Footer links for easy navigation between pages
    - Review form (Auto filtering movie titles)
    - Form validations through JavaScript
    - Dark cinematic theme across the website
